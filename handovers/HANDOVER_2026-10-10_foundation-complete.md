## Gotchas (real failures from this session)

- **bit-reviewer 403:** did not recur; reviews posted fine via cold `bit:pr-review` agents. A review cannot be re-posted on the same head; the reviewer sometimes cannot mark ready (controls gate refuses on a non-PR-head checkout, or STD-0006 not_evaluated) -- then mark ready and request Ben as `bit-author` by hand.
- **PRs as `bit-author`:** `GH_TOKEN=$(python ".../skills/pr/gh_app_token.py" --app author)`; push with Ben's credentials. Force-pushing a rebased branch clears the review request; re-add `bitwomey`.
- **Strict branch protection:** a PR falls `BEHIND` whenever another merges; rebase and re-run CI.
- **Windows long paths:** removing agent worktrees fails with "Filename too long"; `git worktree remove --force` then `Remove-Item -LiteralPath '\\?\C:\...'` with a literal path (not an interpolated one).
- **YAML:** an unquoted `(default: ...)` in a workflow input description broke the whole file (GitHub says only "workflow file issue"); validate with `npx -y @action-validator/cli <file>`.
- **Tailwind 4:** `outline-none` + `outline-2` never paints a focus ring; use `data-[focus-visible]:outline-solid`. Unlayered token type-role classes beat utilities (`font-normal!`).
- **Hooks:** a mojibake guard blocks shell commands containing non-ASCII characters (write such text with the Write tool); a secrets guard blocks env dumps.
- **Stale local lockfile:** `npm install` can modify `package-lock.json` after a merge; discard before pulling.
- Never kill processes by image name (`taskkill /IM`); other sessions share the box.
